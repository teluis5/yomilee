【デザイン・レイアウト変更ガイド】

Astroブログのデザインは、この `src/` フォルダ内の各ファイルを編集することでカスタマイズできます。

■ デザインを変更する主なファイル：

1. 全体のカラー・フォント・余白
   -> `styles/global.css` を編集します。

2. ヘッダー（上部のナビゲーションバー）
   -> `components/Header.astro` を編集します。

3. フッター（下部のコピーライトやリンク）
   -> `components/Footer.astro` を編集します。

4. 記事ページのデザイン（タイトルや日付の配置、広告の位置など）
   -> `layouts/BlogPost.astro` を編集します。

5. トップページ（記事一覧や最初の挨拶など）
   -> `pages/index.astro` を編集します。

※ カスタマイズのご要望があれば、AIエージェントに「トップページの記事一覧をカード型にして」「ヘッダーをダークモード風にして」などとチャットで指示していただければ、自動でコードを書き換えます！
