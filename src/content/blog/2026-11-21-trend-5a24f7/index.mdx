**六花亭オンラインショップで決済画面の改ざんにより約8,000件の流出懸念が発生**しました。

2026年11月21日の第二報では個人情報流出の可能性と、約5万円の不正利用1件の確認が公表されています。

2026年11月21日時点の六花亭公式発表をもとに、対象条件と被害を防ぐ手順を整理しました。

## 六花亭の不正アクセス対象は2026年10月21日〜11月18日の約8,000件

**対象は2026年10月21日21:00〜11月18日11:00の間に決済画面へ入力した利用者**です。

サイトサーバーへのカード番号保存はなく、入力情報を外部へ送信する「Webスキミング」の手口が確認されました。

| 発表・被害項目 | 2026年11月21日時点の公式発表 |
| :--- | :--- |
| **対象サイト** | 六花亭オンラインショップ（11月18日から停止継続中） |
| **対象期間** | 2026年10月21日（水）21:00 〜 11月18日（水）11:00 |
| **対象件数** | 約8,000件（決済画面で情報を入力した件数） |
| **カード流出懸念** | カード番号全桁・名義人・有効期限・セキュリティコード |
| **個人情報流出懸念** | 氏名・郵便番号・住所・電話番号・メールアドレス（11/21追加） |
| **不正利用の確認** | 顧客申し出により約5万円の不正利用を1件確認（11/21発表） |

- <b>判明当日の対応：</b> 六花亭は11月18日に不具合を把握した当日にオンラインショップを緊急停止。
- <b>個別連絡の実施：</b> 対象となる可能性がある利用者へ向けて、六花亭から順次メール等で連絡を実施中。
- <b>未発表の項目：</b> オンラインショップの具体的な再開日時は調査進展と安全性確認後に改めて告知予定。

## 該当利用者が今すぐ行うべきクレジットカード再発行と防衛策3点

**対象期間に注文した記憶がある人は、通知を待たずカード会社へ再発行を依頼する行動が最優先**です。

すでに不正利用が1件確認されているため、セキュリティコードを含めたカード番号の入れ替えが安全確保につながります。

1. <b>カード裏面窓口へ連絡：</b> 利用したクレジットカード裏面の電話番号へ連絡し、「六花亭から流出懸念の通知を受けた」と伝えて再発行を依頼。
2. <b>利用明細を過去1ヶ月確認：</b> 10月21日以降の明細に数千円〜数万円の不審な請求がないかチェックし、異変があれば即時申告。
3. <b>偽SMSの遮断：</b> 流出懸念のあるメールや電話への「補償」「パスワード入力」誘導はすべてフィッシング詐欺のため警戒。

> <b>二次被害に注意：</b> カード会社や六花亭が電話・SMSで暗証番号やパスワードを聞き出すことはありません。

## よくある質問（FAQ）

### Q. 10月21日より前に六花亭オンラインショップを使った場合は安全ですか？
公式発表で対象とされているのは「2026年10月21日21:00〜11月18日11:00」の入力分です。時期が異なる場合でも念のため明細確認の習慣を持つと安心です。

### Q. カードを再発行すると、公共料金やサブスクの支払いはどうなりますか？
カード番号が変わるため、携帯料金や動画配信・電気ガス等の継続課金へ新番号の再登録が必要です。カード会社によっては自動引き継ぎされる場合もあります。
