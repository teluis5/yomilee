**イオンフードスタイル小平店は2026年11月27日（金）朝9時にリニューアルオープン**します。

ショッピングセンター名称を「イオン小平」とし、1階フロアを中心に地域の日常買い物拠点として刷新されます。

2026年11月21日時点の公式案内をもとに、営業時間変更や駐車場割引ルールまで整理しました。

## イオンフードスタイル小平店は11月27日9時開業・12月から朝8時営業

**11月27日〜30日は9:00〜22:00、12月1日以降は朝8:00〜22:00**へ営業時間が拡大します。

通勤・通学前の早朝時間帯から夜遅くまで使える、地域密着型の営業体制となります。

| 項目 | 店舗詳細 |
| :--- | :--- |
| **店舗名** | イオンフードスタイル小平店（イオン小平 1階） |
| **開業日** | 2026年11月27日（金）9:00 |
| **所在地** | 〒187-0031 東京都小平市小川東町2-12-1 |
| **営業時間** | 9:00〜22:00（12月1日以降は8:00〜22:00予定） |
| **駐車場** | 合計約316〜340台（地下・第2・第4駐車場） |

一部売場や専門店では営業時間が異なる場合があるため、目当てのサービスがある際は事前確認が安心です。

## 駐車場は買物で最大4時間無料！場所ごとの料金ルール

**税込1,000円以上のお買い上げで、すべての駐車場が最大4時間まで無料**になります。

入庫直後の無料時間は駐車場の場所によって異なるため、滞在時間に合わせて選ぶと無駄がありません。

- <b>地下駐車場・第2駐車場：</b> 入庫から2時間無料。買物特典（税込1,000円以上）で最大4時間無料。
- <b>第4駐車場（店舗正面）：</b> 入庫から1時間無料。買物特典（税込1,000円以上）で最大4時間無料。
- <b>駐車収容台数：</b> 合計約316〜340台を備え、週末の家族連れでのまとめ買いにも対応。

短時間のちょい買いなら店舗正面の第4駐車場、ゆっくり回るなら2時間無料の地下・第2駐車場が便利です。

## 正確な立地・Googleマップ・右折入庫不可の交通注意

西武多摩湖線「八坂駅」から徒歩約3〜6分と駅近で、府中街道（都道17号線）沿いに位置します。

- <b>電車アクセス：</b> 西武多摩湖線「八坂駅」徒歩約3〜6分、西武線「久米川駅」徒歩約12分、「小川駅」徒歩約13分。
- <b>バスアクセス：</b> 西武バス「八坂駅前」停留所下車、徒歩約2〜4分。

## よくある質問（FAQ）

### Q. イオンフードスタイル小平店の朝8時開店はいつからですか？
2026年11月27日〜30日は9:00開店ですが、2026年12月1日以降は8:00〜22:00の営業に変更予定です。

### Q. 駐車場は買い物しなくても無料で停められますか？
地下・第2駐車場は入庫2時間、正面の第4駐車場は入庫1時間まで無料です。税込1,000円以上の買い物で全駐車場が最大4時間無料になります。
