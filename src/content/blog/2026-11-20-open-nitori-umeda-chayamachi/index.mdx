大阪・梅田の茶屋町エリアに**「ニトリ 梅田茶屋町店」**が誕生しました。ニトリ店舗として世界最大規模の旗艦店で、2026年10月30日（金）にオープンしています。

旧・梅田ロフト跡地の地上1階〜8階すべてを活用した総売場面積約2,700坪の大型店舗です。アパレルや家電から家具、法人・リフォームショールームまで1か所で揃います。本記事は2026年11月時点の公式発表および公開店舗情報をもとに要点を整理しました。

## 地上1階〜8階・約2,700坪のフロア構成と注目ポイント

ニトリ 梅田茶屋町店は、8フロアに明確な役割分担があるのが特徴です。家具・雑貨だけでなく、アパレル・家電・法人向けショールームまで揃います。

| フロア | 主な取扱ジャンル・特徴 |
| :--- | :--- |
| **1階** | アパレル（N+、島忠のN easy、ルームウェア等）、季節商品、家電、ホームファッション |
| **2〜4階** | ホームファッション（寝具・カーテン・キッチン用品・収納雑貨）、家電 |
| **5〜7階** | 家具（ソファ・ベッド・ダイニング）、トータルコーディネートルーム |
| **8階** | 法人向けショールーム、リフォームショールーム |

### 1. 駅近の都心型ビルでありながら約2,700坪の圧巻スケール
郊外型ロードサイド店並み、あるいはそれを上回る約2,700坪の売場が梅田の中心部に誕生しました。仕事帰りやショッピングのついでに立ち寄れる都心立地で、大型家具から日用雑貨まで一度に比較検討できます。

### 2. 1階からアパレル・ルームウェア・家電を充実展開
1階のエントランスフロアには、アパレルブランド「N+」や島忠系の「N easy」が並びます。ニトリのルームウェアも揃い、普段の買い物客も気軽に入りやすい構成です。

### 3. 5〜8階はコーディネートルームと専門ショールームに特化
上層階（5〜7階）には部屋全体のイメージを掴めるトータルコーディネートルームを用意しています。最上階の8階には法人向け・リフォーム専用のショールームも備わり、引っ越しや模様替えの相談に便利です。
