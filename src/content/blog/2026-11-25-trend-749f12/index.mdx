<b>2026年11月25日の東京株式市場で、日経平均株価の下げ幅が一時2,000円を超え、前日比1,633.01円安の57,011.62円で取引を終えました。</b>

前日24日に2,200円超の急反発を見せたばかりにもかかわらず、わずか1日で大型ハイテク・半導体株へ激しい売りが戻った形。

原因は米国市場の半導体指数下落、エヌビディア株安とAI投資への警戒感、トランプ政権の関税報道、さらに前日急騰の反動の4点です。

ただし医薬品や食料品には買いが入っており、全面安だった11月20日とは相場の中身が異なるため、パニック売りだけは避けるべき局面。

## 11月25日の日経平均急落はなぜ起きた？4つの下落理由

<b>寄与度の高い半導体・AI主力株が売られた一方、内需ディフェンシブ株へ資金が逃避する選別色の強い下落でした。</b>

背景にある4つの悪材料が同時に重なり、朝方から指数全体を強く押し下げる展開になりました。

| 下落要因の分類 | 11月25日に意識された具体材料 |
| :--- | :--- |
| **① 米ハイテク・SOX安** | 24日の米ナスダック・SOX指数が反落し、国内のアドバンテストや東京エレクトロンへ売り波及 |
| **② AI相場への懐疑論** | エヌビディア株の約6%下落に加え、新規上場のAI企業アンソロピックの公開価格割れを嫌気 |
| **③ 米国の関税政策警戒** | トランプ政権による欧州・中国等への新たな関税引き上げ措置報道でリスク回避ムード拡大 |
| **④ 前日急騰の利益確定** | 24日の2,200円超上昇を受け、ボラティリティ拡大の中で戻り待ち売り・利確売りが集中 |

特に、直近でジェンスン・ファンCEO復帰を受けて買われていたエヌビディアが輸出規制の不透明感で反落した影響が直撃。

さらにAI大手アンソロピックの上場直後の軟調さも重なり、「AI投資の採算性に慎重な目線」が一気に強まった1日でした。

## 11月20日暴落との違いは？内需株の底堅さと個人投資家の動き方

<b>11月20日の3,000円超安が市場全体の全面安だったのに対し、11月25日は医薬品や食料品など内需ディフェンシブ株が買われました。</b>

日経平均自体は1,600円超下がっていても、すべての業種が崩れているわけではなく、半導体偏重の指数ゆえに下落幅が大きく見えた側面。

乱高下（高ボラティリティ）が続く相場では、信用取引のレバレッジを張ったまま翌日の値動きを待つのはリスクが高すぎます。

### 今後の日本株で様子見すべき人・押し目を拾う人の線引き

<b>半導体株に資産が偏っている人は、数日の落ち着きを確認してから比率を調整すべきであり、急落当日のナンピン買いは控えるのが無難です。</b>

逆に長期の積立NISAや配当狙いの内需株が中心なら、指数の1日単位のノイズで売却せずそのまま保有を続ける判断が合理的。
