**復元された首里城正殿が2026年11月23日（月・祝）に一般公開を迎え、有料区域料金が大人1,000円へ改定されました。**

正殿の「内部」を観覧するには原則として日時指定のWEB事前予約が必要で、外観見学のみなら通常チケットで入場できます。

2026年11月23日時点の首里城公園公式案内に基づき、観覧ルールとアクセス手順をまとめました。

## 首里城正殿の入場料（大人1,000円）と営業時間

**11月23日の公開に合わせて有料区域の料金体系が改定され、4月〜11月期は19:00まで入場可能です。**

無料区域と有料区域で開園時間が異なるため、訪問時間帯に合わせた動線確認が重要です。

| 区分・項目 | 2026年11月23日以降の公式案内 |
| :--- | :--- |
| **一般公開開始日** | 2026年11月23日（月・祝） |
| **城郭内 無料区域** | 8:00〜19:30（4月〜11月期） |
| **城郭内 有料区域** | 8:30〜19:00（最終入場締切 18:30） |
| **入場料（大人）** | 1,000円 |
| **入場料（高校生 / 小中学生）** | 高校生 760円 / 小・中学生 370円 |
| **無料対象** | 6歳未満、70歳以上の沖縄県民（証明書等要確認） |

- <b>冬季の営業時間注意：</b> 12月〜3月は日没に合わせて有料区域の閉園時間が早まる場合があります。
- <b>当日券の販売：</b> 広福門券売所などで通常購入できますが、正殿内部の観覧枠とはルールが分かれます。

## 正殿「内部」観覧のWEB予約ルールと外観見学の違い

**正殿の建物内部まで立ち入って見学したい場合は、事前の日時指定WEB予約が原則必須です。**

予約なしで現地へ到着しても、枠が埋まっていれば内部へ入れないため、出発前の手配が欠かせません。

1. <b>正殿内部の見学：</b> 原則として日時指定のWEB事前予約が必要。予約枠に空きがある場合のみ当日券売所等で購入可。
2. <b>正殿外観の見学：</b> 有料区域チケット（大人1,000円）を購入すれば、事前予約なしでも外観の鑑賞が可能。
3. <b>混雑回避の目安：</b> 一般公開直後の祝日・週末はチケット窓口が混み合うため、午前中の早い枠の予約が安心。

> <b>来園前の確認：</b> チケット予約状況や臨時交通規制の最新情報は、首里城公園の公式サイトで出発当日に確認してください。

## よくある質問（FAQ）

### Q. 首里城正殿の内部を見るのに予約は絶対に必要ですか？
はい、原則として日時指定のWEB事前予約が必要です。予約枠に空きが残っている日時に限り、当日でもWEBや券売所で購入できます。

### Q. 予約を取れなかった場合、現地に行っても無駄になりますか？
いいえ、有料区域チケットを買えば正殿の外観や御庭の見学は可能です。また守礼門などの無料区域も予約なしで散策できます。
