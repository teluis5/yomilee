**「ららぽーとTOKYO-BAY」北館建替え計画のⅡ期エリア新築工事が、2026年11月4日に正式着工**しました。

三井不動産の公式発表によると、2028年夏の全面開業を予定しており、完成後は施設全体で約600店舗の巨大モールへ進化します。

2026年11月23日時点で2026年11月上旬の建設開始と施工体制も判明しており、Ⅱ期エリアの確定スペックを最新化しました。

## 北館Ⅱ期は2026年11月4日着工・大成建設施工で2028年夏開業へ

**2025年10月に先行開業したⅠ期エリアに続き、最終段階となるⅡ期工事が2026年11月上旬より本格始動**しました。

北館の再開業エリアでは店舗数が従来の約150店舗から約200店舗へ拡大し、日本最大級の集積規模となります。

| 項目 | 発表済みスペック・工程 |
| :--- | :--- |
| **計画名称** | ららぽーとTOKYO-BAY 北館建替え計画（Ⅱ期エリア） |
| **着工日・施工** | 2026年11月4日着工 / 大成建設株式会社 |
| **全面開業予定** | 2028年夏 |
| **店舗規模** | 北館約200店舗（施設全体で約600店舗） |
| **所在地** | 千葉県船橋市浜町2丁目1番1号 |

- <b>低CO2鋼材の採用：</b> 大成建設の施工により、東京製鐵の低CO2鋼材「ほぼゼロ」を約3,500t採用する環境配慮方針。
- <b>未発表の項目：</b> Ⅱ期エリアに入居する約200店舗の個別ブランド一覧や開業記念イベントは2026年11月時点で未発表。

## 屋内型スタジアムコート3倍化とハーバー通り拡幅の3大注目点

**1981年の1号店開業以来親しまれてきた中央広場と屋外動線が、体験重視の空間へ刷新**されます。

デザインコンセプトに「インダストリアルワーフ（工業埠頭）」を掲げ、港湾都市・南船橋の文脈を取り入れた設計です。

1. <b>屋内スタジアムコート：</b> 中央広場を従来の約3倍の広さへ拡大し、天候に左右されないスポーツ・音楽イベント拠点へ刷新。
2. <b>ハーバー通りの拡幅：</b> 全長約350mの屋外空間を幅員2倍へ広げ、南館の「かいだん広場」を含めて人工芝生広場や遊具エリアを新設。
3. <b>Ⅰ期エリアとの連携：</b> 先行オープン済みのⅠ期棟や西館・南館と回遊動線がつながり、1日中滞在できる構造。

> <b>工事期間中の利用注意：</b> Ⅱ期工事エリア周辺は仮囲いや歩行ルートの変更が生じるため、現地案内表示に従った移動が必要です。

## よくある質問（FAQ）

### Q. 北館Ⅱ期の工事中も、ららぽーとTOKYO-BAYの他エリアは営業していますか？
はい、南館・西館および2025年10月開業の北館Ⅰ期エリアは通常通り営業しています。一部駐車場や連絡通路の動線のみ工事に伴い変更されます。

### Q. Ⅱ期エリアの新店舗ラインナップはいつ発表されますか？
2028年夏の全面開業に向けて、2027年後半から2028年春頃に三井不動産より順次公表される見込みです。
