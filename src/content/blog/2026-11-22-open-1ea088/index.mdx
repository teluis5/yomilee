**地域発展型の酒蔵「白川村の蔵」が、2027年4月に岐阜県白川村で稼働・開業予定**です。

白川村と飛騨古川の老舗・渡辺酒造店（「蓬莱」蔵元）がタッグを組み、旧白川小学校跡地を活用する計画。

2026年11月22日時点の白川村公式情報と現地進捗をもとに、施設の特徴とアクセスを整理しました。

## 白川村の蔵は2027年4月稼働予定・約100年ぶりの酒蔵復活

**白川村内で途絶えていた酒蔵を約100年ぶりに復活させる6次産業化プロジェクト**です。

1階に日本酒醸造の工場と直売ショップ、2階に見学コーナーを設ける2層構成で建設が進んでいます。

| 項目 | プロジェクト・施設詳細 |
| :--- | :--- |
| **施設名称** | 白川村の蔵 |
| **開業・稼働予定** | 2027年4月予定 |
| **建設地** | 岐阜県大野郡白川村鳩谷614-1（旧白川小学校跡地） |
| **共同事業者** | 白川村 × 有限会社渡辺酒造店 |
| **予定フロア構成** | 1階：酒造工場・ショップ / 2階：見学コーナー |

- <b>豪雪地帯対応：</b> 積雪の多い白川村の気候に耐える強固な建物構造を採用して工事を実施。
- <b>地元酒米の活用：</b> 耕作放棄地を防ぎ景観を守るため、村内で酒米「山田錦」の試験栽培と拡大を進行。

## 現地見学会の開催と合掌造り観光との相乗効果

**2026年11月には工事中の建屋や酒米栽培田を巡る現地見学会が開かれ、完成への期待が高まっています**。

従来の日帰り中心だった白川郷観光を、食事や地酒体験を含む「滞在型観光」へ引き上げる狙いです。

1. <b>純村産ストーリー：</b> 白川村の清冽な水と村内で育てた米で仕込む、地域密着型の地酒ブランドを創出。
2. <b>見学体験の導入：</b> 2階の見学スペースから仕込み工程を眺められるため、観光客の立ち寄り拠点に好適。
3. <b>ショップ展開：</b> 蔵元限定酒や酒粕スイーツ、お土産品の販売など、直売所ならではの展開に期待。

> <b>一般営業の注意点：</b> 2026年11月時点の現地見学会は地元住民・関係者中心です。一般客向けの試飲開始日や営業時間は2027年春の公式発表待ち。
