## 名古屋市立大「1秒間誤通知」の発生経緯と影響人数

**対象は「令和9年度学校推薦型選抜A」第1段階選抜で、医学部保健医療学科看護学専攻の受験生**です。

本来は1次試験の合格者のみがダウンロードできる「2次試験受験票画面」が、1秒間だけ不合格者側にも露出。

| 項目 | 発表・調査内容の詳細 |
| :--- | :--- |
| **発生日時** | 2026年11月13日（金）17:00:00〜17:00:01 |
| **対象選抜** | 令和9年度学校推薦型選抜A（第1段階選抜） |
| **不合格者総数** | 80名 |
| **誤閲覧・DL人数** | 3名（医学部保健医療学科看護学専攻） |
| **原因区分** | 不合格者データのアップロード反映タイムラグ |

- <b>大学側の対応：</b> アクセスログ調査で3名を特定し、個別に連絡・謝罪したうえで正式な不合格結果を伝達。
- <b>不正アクセスの否定：</b> 外部からの改ざんやセキュリティ侵害ではなく、運用上の時刻反映ズレによる現象と公表。

## なぜ「1秒のタイムラグ」が起きたのか（ITシステム視点）

**発表時刻の17時直前に運用マニュアルどおり不合格データを登録した際、システム反映が1秒遅れたこと**が直接要因です。

合格発表は17時00分ジャストにアクセスが集中するため、アクセス制御とデータ更新の同期処理が極めて重要になります。

1. <b>公開時刻と同期のズレ：</b> 画面公開タイマーは17:00:00に解除されました。一方で不合格者フラグの反映は17:00:01へ遅れた構造。
2. <b>デフォルト表示の落とし穴：</b> 「不合格フラグが未反映のアカウントにも2次試験画面を見せる設計」になっていた点も課題。
3. <b>手動アップロードのリスク：</b> 発表直前のデータ投入ではなく、事前反映と公開フラグの一括切り替えが安全な設計。

> <b>受験生側の注意点：</b> Web合格発表では通信遅延やキャッシュ表示が起きる場合があります。大学公式の「合格者受験番号一覧」や書面との二重確認が安全。
