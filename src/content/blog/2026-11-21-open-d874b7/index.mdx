**イオンモール伊達は2026年11月20日から26日までソフトオープンを実施中**です。

正式なグランドオープンは2026年11月27日（金）朝9時で、約170店舗が集結します。

2026年11月21日時点の公式案内と現地プレオープン状況をもとに、最新情報へ更新しました。

## イオンモール伊達は11月20日〜26日プレオープン、27日正式開業

**ソフトオープン期間（11月20日〜26日）は一般客も入場可能で、初日から行列が発生**しました。

グランドオープンは2026年11月27日（金）午前9時に予定されています。

| 項目 | 施設詳細 |
| :--- | :--- |
| **施設名** | イオンモール伊達 |
| **プレオープン** | 2026年11月20日（金）〜11月26日（木） |
| **開業日** | 2026年11月27日（金）9:00 |
| **所在地** | 〒960-0406 福島県伊達市堂ノ内地区土地区画整理事業地内 |
| **店舗数** | 約170店舗（外部棟含む・東北初26店 / 福島初48店） |
| **駐車場** | 約3,600台（駐車料金無料） |

雨天となったソフトオープン期間中も、東北初・福島初ショップを中心に長い列ができました。

- <b>行列ができた人気店：</b> バーガーキング、ゴンチャ、カプセルトイエリアなどで長時間の待ち列が発生。
- <b>早期完売への注意：</b> プレオープン初日から一部店舗で人気商品が早期に完売する動きが出ています。
- <b>1階エリア：</b> 食品・食物販ゾーン「FOOD MARCHE」とユニクロ・ジーユーなどを配置。
- <b>2階・3階エリア：</b> 県内最大級の無印良品やフードコート「FOOD FOREST」、もくいくひろばを完備。

> <b>開業直後の特別営業に注意：</b> 11月27日〜29日の3日間などは開店時刻が前倒しされる場合があります。来館前に公式案内を確認してください。

## 正確な立地・Googleマップ・車と電車アクセス

## よくある質問（FAQ）

### Q. イオンモール伊達のプレオープンや試験営業には誰でも入れますか？
2026年11月20日〜26日のソフトオープン期間中は一般客も利用可能です。人気飲食店を中心に混雑や売り切れが出ているため、午前中の来館がおすすめです。

### Q. 駐車場は有料ですか？何台停められますか？
駐車場は約3,600台を完備し、駐車料金は無料です。東北中央自動車道の伊達桑折ICに隣接するため、遠方からも車での来館がスムーズです。
