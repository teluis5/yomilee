## 1. povoのAPN設定（結論アンサー＆コピペ一覧表）

### 【結論】povo（povo2.0）のAPN設定値まとめ

<b>povo（povo2.0）のAPN設定</b>は、APN欄に「<code>povo.jp</code>」、APNプロトコルに「<code>IPv4/IPv6</code>」を入力して保存するだけで完了します。
なお、iPhone（iOS 14.5以降）は自動認識されるため手動のAPN設定は不要です。

* <b>名前：</b> <code>povo2.0</code>（任意の名前）
* <b>APN：</b> <code>povo.jp</code>（<b>必須・半角小文字</b>）
* <b>APNプロトコル：</b> <code>IPv4/IPv6</code>（<b>必須</b>）
* <b>APNタイプ：</b> <code>default,supl,dun</code>（テザリング必須）
* <b>MCC / MNC：</b> <code>440</code> / <code>51</code>（未入力時のみ）

### povo APN設定値の完全一覧表（Android手動入力・コピペ用）

Android端末のAPN設定画面で迷わないよう、全項目の入力値を一覧表にまとめました。
<b>太字の項目以外はすべて「未設定（空欄）」のまま</b>で問題ありません。

| 設定項目 | 入力値（コピペ用） | 補足・ポイント |
| :--- | :--- | :--- |
| <b>名前</b> | <code>povo2.0</code> | 任意の名前でOK（識別用） |
| <b>APN</b> | <code>povo.jp</code> | <b>半角小文字・必須</b>（前後にスペースを入れない） |
| <b>ユーザー名</b> | （未設定 / 空欄） | 入力不要 |
| <b>パスワード</b> | （未設定 / 空欄） | 入力不要 |
| <b>認証タイプ</b> | 未設定（または CHAP） | 繋がらない場合は「CHAP」を選択 |
| <b>APNタイプ</b> | <code>default,supl,dun</code> | <b>テザリングを使うなら dun 必須</b>（後述） |
| <b>APNプロトコル</b> | <code>IPv4/IPv6</code> | <code>IPv4</code> のみだと繋がらない場合あり |
| <b>APNローミングプロトコル</b> | <code>IPv4/IPv6</code> | 海外ローミング時用 |
| <b>MCC</b> | <code>440</code> | <b>日本を表す国番号</b>（SIM認識時は自動入力） |
| <b>MNC</b> | <code>51</code> | <b>KDDIを表す事業者コード</b>（SIM認識時は自動入力） |
| <b>ベアラー</b> | 未指定 | 初期値のままでOK |

<AdviceBox title="MCC（440）とMNC（51）で混乱する原因">
  <p>通常、SIMカードを挿した状態であればMCCとMNCは自動で「440」と「51」が入力されます。</p>
  <p>しかし、<b>SIM挿入前にAPNを作成しようとした場合</b>や<b>海外版スマホ</b>では自動判定されません。空欄になって進めない時は、手動で <b>MCC: 440 / MNC: 51</b> を入力すれば解決します。</p>
</AdviceBox>

## 2. 【OS別】povoのAPN設定手順（Android / iPhone）

### Androidのpovo APN設定手順（8ステップ）

1. 「<b>設定</b>」アプリを開く
2. 「<b>ネットワークとインターネット</b>」（または「モバイルネットワーク」）をタップ
3. 「<b>SIM</b>」から povo2.0 の回線を選択
4. 画面下部の「<b>アクセスポイント名（APN）</b>」をタップ
5. 右上の「<b>＋</b>」ボタン（または「追加」）をタップ
6. 表どおりに「名前（<code>povo2.0</code>）」「APN（<code>povo.jp</code>）」等を入力する
7. <b>【超重要】</b> 右上のメニューアイコン（︙）から「<b>保存</b>」をタップ
8. APN一覧に戻り、作成した「<b>povo2.0</b>」のラジオボタン（丸印）を選択する

### iPhone（iOS）のpovo APN設定手順

<b>iPhone（iOS 14.5以降）では、原則としてpovoのAPN手動設定は不要です。</b>
Wi-Fi接続状態でSIMを挿入し、最新のキャリア設定アップデートを適用すれば自動で認識されます。

もしiPhoneで繋がらないなら、原因は<b>「以前使っていた格安SIMの構成プロファイル」</b>です。
手動入力は不要なので、すぐ下のチェックリスト②の手順で古いプロファイルを削除してください。

## 3. povoのAPN設定をしても繋がらない・圏外の時の7つの対処法

APNを設定したのにネットに繋がらない時は、以下の7項目を上から順に確認してください。

### ① 【Android】APN設定後に「保存」して選択したか？
Androidで最も多いミスが、<b>「入力したのに右上のメニューから保存を押さずに戻った」</b>ケースです。
また、保存しただけで<b>一覧画面のラジオボタン（丸印）にチェックを入れていない</b>パターンも頻発します。

もう一度APN一覧を開き、作成した「povo2.0」が選択状態になっているか確認しましょう。

### ② 【iPhone】過去の「APN構成プロファイル」が残っていないか？
ワイモバイル、UQモバイル、mineo、IIJmio等から乗り換えたiPhoneに最多の原因です。
他社の構成プロファイルが1つでも残っていると、povoの電波を正常に掴めません。

* <b>削除手順：</b>「設定」＞「一般」＞「<b>VPNとデバイス管理</b>」を開く
* 古い通信事業者のプロファイルを選択し、「<b>プロファイルを削除</b>」をタップして再起動する

### ③ アプリでの「SIM有効化手続き」は完了しているか？
SIMカードが届いただけでは通信できません。
必ずpovo2.0アプリから「<b>SIMカードの有効化</b>」を行う必要があります。

### ④ 機内モードのON/OFF・端末の再起動をしたか？
APN設定が正しくても、スマホが古い基地局情報を掴んだままで電波を再サーチできないことがあります。
* <b>クイック設定から「機内モード」をONにして5秒待ってからOFFにする</b>
* 改善しない場合は<b>スマートフォンの電源を一度切って再起動</b>する

これだけでアンテナピクトがスッと立ち、4G/5G通信が始まるケースが多々あります。

### ⑤ デュアルSIM運用時：モバイルデータ通信が「povo」になっているか？
物理SIM＋eSIMなどで2回線を併用している場合、データ通信用のSIMが別回線のままになっていることがあります。
* <b>Android：</b>「設定」＞「ネットワークとインターネット」＞「SIM」からモバイルデータをpovoに切り替える
* <b>iPhone：</b>「設定」＞「モバイル通信」＞「モバイルデータ通信」でpovoにチェックを入れる

### ⑥ テザリングが繋がらない：APNタイプに「dun」が入っているか？
スマホ単体ではネットが見られるのに、PCへのテザリングだけ繋がらないトラブルです。
原因はAPNタイプの設定不足にあります。

APN設定の「APNタイプ」を以下のように書き換えて保存してください。
```text
default,supl,dun
```
※ <code>dun</code> はテザリング通信を許可する識別子です。
Pixelシリーズや海外製SIMフリー端末では、これを明記しないとテザリングがブロックされます。

### ⑦ 発信テスト用番号「111」へ電話をかけてみる
データ通信（APN）だけの問題か、回線自体が未開通なのかを切り分けましょう。
KDDIの開通確認用テスト番号へ発信すると一発で判別できます。

* <b>電話アプリから <code>111</code>（通話料無料）へダイヤルする</b>
* ガイダンス「接続試験は終了です」が流れれば、SIMの開通自体は正常に完了しています。

もし「111」にも繋がらない場合は、SIMカードの接触不良やSIMロック未解除が原因です。

## 4. 開通後の注意点：最初は「128kbps」＆「180日ルール」

無事にpovoのAPN設定が完了してネットに繋がったら開通完了です！
ただし、利用開始直後は以下の2点を知っておきましょう。

### 開通直後は通信速度が最大128kbps
povo2.0は基本料0円の仕様上、初期状態では「トッピング未購入」のため通信速度が<b>最大128kbps</b>に制限されています。
「APN設定したのにWebページの表示が遅い！」と焦るかもしれませんが、これは正常な挙動です。

povo2.0アプリから「データ追加」トッピングを購入すれば、即座に高速な4G/5G通信に切り替わります。

### 180日間の未購入による「強制解約」に注意！
povo2.0は基本料0円で維持できるのが最大の強みです。
ただし、<b>「180日間以上有料トッピングの購入がない場合、順次利用停止・強制解約」</b>という規約があります。
