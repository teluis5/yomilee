**大阪駅直結「LUCUA SOUTH」10F〜13Fの「LUCUA キャラクターズワールド」が2026年11月24日開業しました。**

営業時間は10:00〜20:00で、開業から当面の間はフロア入場や人気店舗への入店に整理券が必要になります。

2026年11月24日時点のルクア大阪公式特設サイトおよび各出店ブランド発表に基づき、開店店舗と整理券の仕組みを整理しました。

## ルクア サウス「キャラクターズワールド」は11月24日開業・全国初出店も

**10階〜13階の4フロアに国内最大級のキャラクターショップが集結する新拠点です。**

11月24日に開業した第一陣の店舗に加え、12月以降にも大型ショップが順次オープンする計画となっています。

| 項目 | 公式発表スペック |
| :--- | :--- |
| **施設・ゾーン名** | LUCUA SOUTH（ルクア サウス）10F〜13F LUCUA キャラクターズワールド |
| **グランドオープン日** | 2026年11月24日（火） |
| **所在地** | 大阪府大阪市北区梅田3-1-1 |
| **営業時間** | 10:00〜20:00（商業施設に準ずる） |
| **入場ルール** | 混雑時は事前抽選または当日整理券制 |

- <b>11階注目店：</b> 全国初の「ちいかわパークストア」と「サンリオ ハローステージ」が開店。
- <b>11階追加店：</b> 梅田初の「ナガノマーケット UMEDA」、関西初の「にしむらゆうじ購買部 本店 大阪」も登場。
- <b>12・13階注目店：</b> 西日本初の「STAR WARS STORE by BENELIC」が出店。パペットスンスンやマホウドコロも揃います。
- <b>12月以降予定：</b> 「THE☆JOJO WORLD OSAKA」や「SQUARE ENIX NEXUS」等が順次オープン予定。

> <b>大阪駅周辺の注目点：</b> 12月開業分は店舗ごとにオープン日が異なります。公式特設カレンダーでの事前確認が安全です。

## 整理券なしでは入場不可？「2種類の整理券」と事前準備のポイント

**混雑時は「ゾーン入場整理券」と「個別店舗の整理券」の2段階チェックが必要です。**

どちらか一方の整理券しか持っていない場合、目的のショップに入店できないケースが発生します。

1. <b>ゾーン入場整理券（Airウェイト等）：</b> 混雑日の10F〜13Fエリア自体に入るための整理券で、当日分などが発行されます。
2. <b>各店舗の個別整理券：</b> 人気ショップの入店や購入に求められる整理券で、事前抽選制または先着発券制を採用しています。
3. <b>出発前の必須確認：</b> 対象日や受付開始時刻は日ごとに変動するため、来店当日の朝にルクア公式特設ページで実施有無を確認してください。

- <b>未発表の項目：</b> 12月開業組の具体的なオープン日や年末以降の整理券解除時期は2026年11月24日時点で未発表。
- <b>回遊のコツ：</b> 整理券の対象時間帯までルクア本館やルクア イーレで待機し、呼び出し時刻に合わせて向かう動き方が効率的です。

## よくある質問（FAQ）

### Q. ルクア サウスの「キャラクターズワールド」は何時から何時まで営業していますか？
