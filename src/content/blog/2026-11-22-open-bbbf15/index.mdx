**「アパホテル〈TKP日暮里駅前〉新館（仮称）」が2028年夏に開業予定**です。

株式会社ティーケーピー（TKP）が既存棟の隣接地で開発を進め、日暮里駅から徒歩2分の立地。

2026年11月22日時点のTKP・アパホテル公式発表をもとに、施設計画と立地メリットを整理しました。

## アパホテル〈TKP日暮里駅前〉新館は2028年夏開業・全63室

**既存の本館（278室）と一体運営を行い、合計341室体制へ拡大する計画**です。

新館は鉄骨造・地上10階建てで、ビジネスだけでなくインバウンドやグループ需要を見込んだ客室配分。

| 項目 | 新館（仮称）の計画概要 |
| :--- | :--- |
| **施設名称** | アパホテル〈TKP日暮里駅前〉新館（仮称） |
| **開業予定** | 2028年夏 |
| **所在地（地番）** | 東京都荒川区東日暮里五丁目1132番8 |
| **規模・構造** | 鉄骨造・地上10階建 |
| **客室数** | 全63室（ツイン54室・クイーン9室） |
| **既存棟との合計** | 全341室（既存棟278室＋新館63室） |

- <b>ツイン中心の構成：</b> 新館63室のうち54室（約85%）がツインルームで、家族・友人旅行にも対応。
- <b>一体運営の利点：</b> 隣接する既存棟（東日暮里5-52-9）のフロントや館内設備と連携しやすい配置。

## 日暮里駅徒歩2分と成田空港アクセスの優位性

**京成スカイライナーの発着駅である日暮里駅から近く、空港利用者に抜群の動線**です。

JR山手線・京浜東北線・常磐線も乗り入れるため、東京駅や上野駅、池袋方面へも直通で移動可能。

- <b>成田空港直結：</b> 京成スカイライナー利用で成田空港から日暮里駅まで最短約36分で到着。
- <b>都心移動の速さ：</b> 山手線で上野へ約4分、東京駅へ約12分というビジネス出張に強い立地。
- <b>周辺観光の拠点：</b> 谷中銀座商店街や上野恩賜公園へも徒歩や電車で気軽に足を運べる環境。

> <b>滞在時のチェック点：</b> 新館の宿泊予約開始日や朝食会場の共用ルールは、2028年春の開業直前に公式サイトで公表予定。

## よくある質問（FAQ）

### Q. アパホテル〈TKP日暮里駅前〉新館はいつから予約できますか？
2028年夏開業予定のため、2026年11月時点で予約受付は未開始です。開業数ヶ月前からアパホテル公式サイトで順次公開される見込み。

### Q. 新館の客室にはシングルルームもありますか？
新館（仮称）の計画はツイン54室・クイーン9室の全63室です。1名利用のスタンダード部屋が必要な場合は既存棟（278室）との使い分けが有力。
