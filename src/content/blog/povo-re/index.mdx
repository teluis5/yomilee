## 1. povo2.0は無課金でいつまで使える？（公式ルールと実際の差）

### 公式規約：「180日間のトッピングなし」で順次利用停止

povo2.0の公式サイト（利用規約）には、長期間トッピングを購入していない場合の回線停止について以下のように明記されています。

> <b>180日間以上有料トッピングの購入等がない場合、利用停止、契約解除となる場合があります。</b>  
> ※期間内の国内通話料・国内SMS送信料の合計額が660円（税込）を超えている場合を除きます。

つまり、建前上のルールとしては<b>約6ヶ月間（180日）まったく課金がないとペナルティ対象</b>となります。

### 【実録】申込から強制解約までの時系列スケジュール

では、180日を迎えた翌日にいきなりスパッと回線が切られるのでしょうか？  
実際に私が1円も課金せずに放置し続けた際の日程をまとめました。

| 日付 | 経過期間 | 実際の状況 |
| :--- | :--- | :--- |
| <b>2021/09/30</b> | 0日目 | povo2.0 申込完了 |
| <b>2021/10/02</b> | 2日後 | SIM開通・利用開始（無課金スタート） |
| <b>2022/05/19</b> | 約7ヶ月半（229日後） | <b>「長期間トッピング未購入による利用停止予告」メール到着</b> |

| <b>2022/07/21</b> | 約9ヶ月半（292日後） | <b>契約解除（強制解約）完了の通知</b> |

### 180日を過ぎても一定の「猶予期間（バッファ）」が存在する

実際のタイムラインを見て分かるとおり、180日（約6ヶ月）を過ぎた瞬間に即座に強制解約されるわけではありません。

* <b>開通から約7ヶ月半（約230日）：</b> 事前警告の「利用停止予告メール」が届く
* <b>予告メールから約2週間後：</b> 回線が利用停止（電波が掴めなくなり圏外表示へ）
* <b>利用停止から約1ヶ月半後：</b> 最終的な契約解除（強制解約）が完了

このように、<b>規約の180日を超えてから利用停止まで約2ヶ月弱の猶予期間</b>がありました。

<AdviceBox title="警告メールを見落とさない工夫が大切！">
  <p>povo2.0は突然回線を切るのではなく、事前に<b>「◯月◯日までにトッピングをご購入いただけない場合、順次利用停止となります」</b>という丁寧な案内メールを送ってくれます。</p>
  <p>登録メールアドレスの通知を日頃から受信できるように設定しておけば、慌てて解約されるリスクは大幅に減らせます。</p>
</AdviceBox>

## 2. 強制解約を回避するには？最安トッピングで延命する方法

「電話番号を失いたくない」「サブ回線としてずっと維持し続けたい」という場合は、利用停止になる前に少額の有料トッピングを購入しましょう。

1つでもトッピングを購入した時点で、<b>その日から再び180日間のカウントダウンがゼロにリセット</b>されます。

### 延命におすすめの最安トッピング一覧

1. <b>smash.使い放題パック（220円 / 24時間）</b>  
   動画配信サービスsmash.の使い放題パック。常設トッピングの中では最安で、たった<b>220円（税込）で180日延命</b>できます。
2. <b>データ追加 1GB（390円 / 7日間）</b>  
   外出先でちょっとだけ動画を見たり、メイン回線の通信制限時に使い切るのに最も無駄がありません。
3. <b>通話・SMS送信（過去180日間で合計660円超）</b>  
   有料トッピングを購入しなくても、通話料やSMS送信料が過去180日間で累計660円（税込）を超えていれば利用停止の対象外になります。

<AdviceBox title="年間440円で電話番号を半永久キープ！">
  <p>維持費を極限まで抑えたいなら、<b>半年に1回「smash.使い放題パック（220円）」を購入するだけ</b>です。</p>
  <p>年に2回の課金で済むため、<b>年間わずか440円（月額換算で約36円）</b>という圧倒的な低コストで自分専用の電話番号を維持し続けることができます。</p>
</AdviceBox>

## 3. 強制解約からの「復活」や「再契約」はできる？審査とブラックリストの真実

「電波が止まって圏外になった！同じ電話番号のまま復活できる？」「強制解約された後でもまた契約できる？」という疑問は、<b>「利用停止中」か「契約解除（強制解約）完了後」か</b>で結論が分かれます。

| 現在のステータス | 同じ電話番号での復活 | 新しい番号での再契約（回線復活） |
| :--- | :--- | :--- |
| <b>① 利用停止中</b>（予告メール後〜解除前） | <b>⭕ 復活できる</b>（トッピング購入・チャット申請） | ⭕ 可能 |
| <b>② 強制解約（契約解除）完了後</b> | <b>❌ 復活できない</b>（番号は完全失効） | <b>⭕ 同一名義で即座に再契約できる</b> |

* <b>① まだ「利用停止（圏外）」の段階なら同じ番号で復活可能：</b><br />
  利用停止から最終的な契約解除（強制解約）までは<b>約1ヶ月半の猶予</b>があります。この期間内に有料トッピングを購入（またはサポートチャットへ連絡）すれば、同じ電話番号のまま回線を復活できます。
* <b>② 「契約解除完了」のメールが届いた後は「新規再契約」で復活：</b><br />
  完全に解約された後は、以前の電話番号を復活させることはできません。しかし<b>ペナルティなしで同じ名義・アカウントからすぐに新規再契約（回線復活）が可能</b>です。

### 【実録】強制解約後でも全く問題なく再契約できました！

「利用規約違反で強制解約になったらブラックリスト（不払者情報）に載って、もう二度とpovoやau系列を契約できないのでは？」と不安になる方も多いはずです。

結論からお伝えすると、<b>強制解約後でも何の問題もなく再契約できました。</b>

私は2022年7月に契約解除された後、同年10月にPixel 7 Pro購入時のプロモコードを活用しました。<b>以前と全く同じ名義・同じアカウント</b>でpovo2.0の再申込を行っています。

### なぜブラックリストに載らないのか？

携帯電話業界でいわゆる「ブラックリスト（不払者情報の共有）」に登録されるのは、以下のような悪質なケースです。

* 毎月の通信料金や端末の割賦代金を滞納・踏み倒した
* 端末購入サポートの転売目的等で短期解約を繰り返した
* 不正名義や虚偽申告を行った

povo2.0の「180日間トッピング未購入による契約解除」は、<b>約款（利用規約）に基づいた機械的な自動解約処理</b>に過ぎません。未払い料金を踏み倒したわけではないため、信用情報機関（CIC等）や携帯各社の不払者リストに傷がつくことはありません。

### 再契約時の2つの注意点

ペナルティはありませんが、以下の2点には注意が必要です。

1. <b>以前の電話番号は完全に失効する</b>  
   一度契約解除されると、その電話番号は戻ってきません。再契約時は新しい電話番号での新規発番となります。銀行口座や各種サービスのSMS認証に紐付けている重要番号の場合は、絶対に強制解約させないよう延命してください。
2. <b>同一名義で累計5回線を超える新規契約時の手数料（3,850円）</b>  
   povo2.0は基本的に契約事務手数料が無料。ただし<b>「過去1年以内に同一名義で5回線超を契約する場合」</b>は、6回線目から3,850円（税込）かかります。個人で1〜2回線を再契約する程度なら無料のままです。
