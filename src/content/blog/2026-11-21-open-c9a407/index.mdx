**「（仮称）イオン堀之内」は2028年秋（2028年11月頃）の開業を目指して計画**が進められています。

イオンリテールが2026年9月11日に大規模小売店舗立地法（大店立地法）の新設届出を提出し、商業施設としての具体像が判明しました。

2026年11月21日時点の届出データと計画概要をもとに、開発規模や施設コンセプトを整理しました。

## イオン堀之内は2028年秋開業・店舗面積約7,173㎡で届出

**老朽化した「イオンとやの店」と向かいの旧「とやのプラザ」跡地を一体活用する大型再開発**です。

延床面積は約19,000㎡、店舗面積は7,173㎡に達する見込みで、地域の新たな商業拠点へ生まれ変わります。

| 項目 | 届出・計画スペック |
| :--- | :--- |
| **店舗名称（仮称）** | （仮称）イオン堀之内 |
| **設置者** | イオンリテール株式会社 |
| **開業予定時期** | 2028年秋（2028年11月頃・2027年11月着工予定） |
| **所在地** | 新潟県新潟市中央区堀之内字浦沢55番地1 外30筆 |
| **店舗面積 / 延床** | 店舗面積 約7,173㎡ / 延床面積 約19,000㎡ |

- <b>着工スケジュール：</b> 2027年11月の着工から約1年の工期を経て、2028年11月のオープンを目標とする工程。
- <b>未発表の項目：</b> 入居する専門店テナント名、正確な営業時間、駐車場の最終収容台数は2026年11月時点で未発表。

## 2棟連結構造と屋上公園がもたらす3つの新価値

**道路を挟んだ両敷地をつなぐ「2棟連結の開放的なレイアウト」と屋上公園の整備が大きな特徴**です。

旧清水フードセンター本部の流れを汲む生活密着エリアに、滞在型の新しい買い物環境が加わります。

- <b>敷地一体型の回遊性：</b> イオンとやの店側と旧とやのプラザ跡地を一体開発し、売り場と専門店の行き来がしやすい動線。
- <b>屋上公園・広場の計画：</b> 買い物だけでなく親子連れや地域住民が休憩・交流できる屋上オープンスペースを整備予定。
- <b>笹出線沿いの利便性：</b> 新潟駅南エリアと鳥屋野潟周辺を結ぶ幹線道路沿いで、日常の買い出し機能が大幅に向上。

> <b>再開発の補足：</b> 現「イオンとやの店」の建て替え・移転時期や工事中の営業継続可否については、今後の公式案内で発表されます。

## 正確な出店場所・Googleマップと笹出線沿いのアクセス

**新潟市中央区の主要幹線道路「笹出線」沿いに位置し、新潟駅南口からも車ですぐの立地**です。

大店立地法届出の所在地（新潟県新潟市中央区堀之内字浦沢55番地1周辺）をもとに現地マップを配置しました。

## よくある質問（FAQ）

### Q. 現在の「イオンとやの店」はどうなりますか？
本計画は「イオンとやの店」周辺と旧とやのプラザ跡地を一体的に再整備するものです。現店舗の閉店や切り替え時期の詳細は今後の公式発表をお待ちください。

### Q. 入居するテナント（無印良品やカフェなど）は決まっていますか？
2026年11月時点では設置者（イオンリテール）と面積・構造概要が判明した段階であり、具体的なテナント一覧は未発表です。
