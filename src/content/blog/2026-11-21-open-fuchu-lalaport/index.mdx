**「（仮称）府中市朝日町商業施設計画」は2029年春の開業予定**です。

三井不動産とSMFLみらいパートナーズが手がける延床面積約117,000㎡の大型計画で、「ららぽーと」となる見込みです。

2026年11月21日時点の事業者発表と建設計画情報をもとに、工期スケジュールと立地詳細を整理しました。

## 府中市朝日町商業施設計画は2027年6月着工・2029年春開業予定

**西武多摩川線「多磨駅」から徒歩約2分の約40,000㎡の敷地に、地上5階建て施設を建設**します。

着工は2027年6月中旬、完成は2029年3月末、開業は2029年春のスケジュールで進行中です。

| 項目 | 発表・計画スペック |
| :--- | :--- |
| **計画名称** | （仮称）府中市朝日町商業施設計画 |
| **事業者** | 三井不動産株式会社・SMFLみらいパートナーズ株式会社 |
| **開業予定** | 2029年春（2027年6月中旬着工 / 2029年3月末完成予定） |
| **所在地** | 東京都府中市朝日町三丁目8番1号他 |
| **敷地面積** | 約40,000㎡（39,949㎡） |
| **延床面積** | 約117,000㎡（地上5階・鉄骨造） |
| **最寄り駅** | 西武鉄道多摩川線「多磨駅」徒歩約2分 |

- <b>施設コンセプト：</b> 物販・サービス・飲食に加え、スポーツやエンターテインメント要素を融合した設計。
- <b>周辺環境との連携：</b> 味の素スタジアムや都立武蔵野の森公園に近く、東京外国語大学北側に位置する立地。
- <b>未発表の項目：</b> 正式な施設名称、出店テナント一覧、駐車台数、正確な営業時間は2026年11月21日時点で未発表。

## 多磨駅・味の素スタジアム周辺に大型ららぽーとができる3つの利点

**甲州街道や人見街道に近く、調布・府中・三鷹・小金井エリアの広域ショッピング需要を受け止める拠点**になります。

- <b>駅前徒歩2分の利便性：</b> 西武多摩川線「多磨駅」至近のため、JR中央線（武蔵境駅乗り換え）からの電車来館が容易。
- <b>試合・イベント連携：</b> 味の素スタジアムでのJリーグ観戦やライブ前後の食事・買い物スポットとして機能。
- <b>公園と一体化した滞在：</b> 武蔵野の森公園や野川公園の散策と合わせた家族連れの1日滞在に最適な環境。

> <b>館名の注記：</b> 関連報道で「ららぽーと」見込みとされています。正式な施設名称は着工後に公式発表される予定です。
