<b>「知るカフェ 久留米工業大学店」は2026年11月2日（月）にオープン</b>しました。

九州の私立大学としては初の出店となり、久留米工業大学キャンパス内の交流棟「COM-RIDGE（コムリッジ）」に構えています。

公式案内をもとに、学生無料の仕組みや一般利用料金（1杯200円）、営業時間と場所を整理しました。

## 知るカフェ 久留米工業大学店は九州私大初・学生無料で利用可能

<b>スポンサー企業からの支援で運営され、専用アプリ登録済みの学生はドリンクを無料（0円）で注文</b>できます。

就職活動直前の3・4年生だけでなく、1・2年生の段階から気軽にキャリア形成や業界研究ができる拠点として開設されました。

| 項目 | 公式公表スペック |
| :--- | :--- |
| **店舗名** | 知るカフェ 久留米工業大学店 |
| **オープン日** | 2026年11月2日（月）※10月30日にプレオープン実施 |
| **営業時間** | 12:00〜18:00 |
| **定休日** | 土日祝日、大学のテスト期間 |
| **所在地** | 福岡県久留米市上津町2228-66（久留米工業大学 交流棟COM-RIDGE内） |
| **料金体系** | 学生：無料（専用アプリ登録時）／ 一般・教職員：ドリンク1杯200円 |

- <b>学生スタッフ運営：</b> 店舗のシフトや接客も在学生スタッフが担い、同世代で入りやすい雰囲気。
- <b>一般客の利用条件：</b> 学外からの来訪者や教職員も1杯200円でドリンクを購入可能。

## 低学年から企業と出会える「Meetup」と3つの活用メリット

<b>コーヒーを飲みながら企業の採用担当者や社会人と少人数で話せる「Meetup」を随時開催</b>します。

スーツ着用が必須の合同説明会とは異なり、普段着のまま空きコマにキャリア相談ができる点が支持されています。

1. <b>空きコマの節約：</b> 1日1杯無料制度を活用すれば、キャンパス滞在中のカフェ代を大幅に抑えられる仕組み。
2. <b>早期の業界研究：</b> 工学部・情報系に関心の高い企業と直接対話でき、インターン前の情報収集に有利。
3. <b>交流棟の学習環境：</b> 交流棟「COM-RIDGE」内にあるため、自習やグループワークの合間に立ち寄りやすい配置。

> <b>利用時の注意：</b> 学生無料特典を受けるには、初回注文前に「知るカフェ」公式アプリでの会員登録が必要です。スマートフォンの事前準備をおすすめします。

## よくある質問（FAQ）

### Q. 他大学の学生でも「知るカフェ 久留米工業大学店」を無料で使えますか？
知るカフェは原則として大学の学生証・大学メールアドレス等を紐づけたアプリ登録者が無料対象となります。対象大学や利用区分はアプリ内の案内をご確認ください。

### Q. 土日や夏休み・テスト期間も営業していますか？
定休日は土日祝日および久留米工業大学のテスト期間です。長期休暇中の短縮営業や臨時休業は店舗・アプリ内で告知されます。
