**「アトレ中野」は2026年12月9日（水）にJR中野駅西側の新改札直結で開業します。**

2階から4階のショップゾーンと屋上広場に全73店舗が集結する、中野エリア待望の大型商業施設です。

アトレ公式の開業発表に基づき、フロア別の注目テナントと営業時間・現地場所を整理しました。

## アトレ中野は12月9日開業・全73ショップが線路上空に誕生

**JR中野駅の西側線路上空に建設され、新設される改札と直結する駅ビル型施設です。**

買い物は10:00〜21:00、レストランは11:00〜22:00の基本営業時間で、通勤通学客の日常使いに対応します。

| 項目 | 公式公表スペック |
| :--- | :--- |
| **施設名** | アトレ中野 |
| **開業日** | 2026年12月9日（水） |
| **所在地** | 東京都中野区中野4丁目9番26号 |
| **フロア構成** | 2F〜4F（ショップゾーン）、屋上5F（屋上広場・BBQ） |
| **店舗数** | 全73ショップ |
| **基本営業時間** | 物販 10:00〜21:00 / 飲食 11:00〜22:00（一部店舗除く） |

- <b>線路上空の利便性：</b> 南北の移動がしやすくなり、駅構内から雨に濡れずそのまま2階フロアへ直結。
- <b>時間差営業：</b> 2階のベーカリーやコンビニ（NewDays）などは早朝・深夜のニーズに合わせ営業時間が異なる場合があります。

## フロア別注目テナント！マグロマート新業態や屋上BBQなど

**中野の人気店「マグロマート」の商業施設初業態や、アトレ初となる屋上BBQが最大の目玉です。**

デパ地下並みの総菜・スイーツから生活雑貨・書店まで、普段使いと特別感を両立したラインナップが揃います。

### 屋上（5階）：開放的な広場と本格BBQ
- <b>グリルピア：</b> アトレ初出店となる本格バーベキュー＆ビアガーデン空間。

### 4階：書店・雑貨・カルディが集まる日常フロア
- <b>有隣堂・ハンズ・3COINS＋plus：</b> 本と文具、プチプラ雑貨が1フロアに集約。
- <b>カルディ・Afternoon Tea TEAROOM：</b> 輸入食材や午後のティータイムを楽しめる定番店が出店。

### 3階：カフェ・レストラン・アパレル
- <b>KUA`AINA's Smashed Burger：</b> クア・アイナが手がける新業態のスマッシュバーガー店。
- <b>スターバックス・恵比寿かつ彩・天ぷら 天寅：</b> カフェから和食・居酒屋まで幅広い食事に対応。

### 2階：改札直結のグルメ＆スイーツ街
- <b>鮪々 Sibisibi マグロマート：</b> 中野の予約困難店「マグロマート」による初のマグロ丼専門店。
- <b>成城石井・WithGreen・Soup Stock Tokyo：</b> 仕事帰りに立ち寄りやすいスーパーとヘルシー軽食が充実。
- <b>THE STANDARD BAKERS・ランメイシャ・フルーツピークス：</b> アトレ初出店のベーカリーやタルト専門店が勢ぞろい。

> <b>お土産・総菜も豊富：</b> 2階には「まい泉」「RF1」「クリスピー・クリーム・ドーナツ」など手土産や夕食に便利な総菜店も並びます。

## よくある質問（FAQ）

### Q. アトレ中野の開業日12月9日は何時から入れますか？
基本のショッピング営業時間は10:00〜21:00、レストランは11:00〜22:00です。ただし2階のNewDaysや一部カフェは朝7時〜8時台から営業する場合があります。

### Q. アトレ中野にはスーパーマーケットも入りますか？
はい、2階の改札直結フロアに「成城石井」が出店します。総菜店やベーカリーと合わせて仕事帰りの買い物に便利です。
