**「PARCO_ya名古屋（パルコヤ名古屋）」は2027年春に松坂屋名古屋店 南館へ開業予定**です。

地下2階と1階〜6階の一部にわたる約19,000㎡の売場を大規模刷新し、エリア初出店を含む約100店舗が出店します。

2026年11月時点のパルコ公式リリースに基づき、施設規模やコンセプト、アクセス動線を整理しました。

## PARCO_ya名古屋は松坂屋南館の約19,000㎡に約100店舗を展開

**大丸松坂屋百貨店とパルコ（J.フロントリテイリンググループ）が連携する大型リニューアル計画**です。

上野に続く「PARCO_ya」屋号として、従来のヤング層向けビルとは一線を画す大人・高感度層向けの商業空間を設けます。

| 項目 | 公式公表スペック |
| :--- | :--- |
| **施設名称** | PARCO_ya名古屋（パルコヤ名古屋） |
| **開業時期** | 2027年春予定 |
| **所在地** | 愛知県名古屋市中区栄三丁目16番地1号（松坂屋名古屋店 南館） |
| **対象フロア** | 地下2階、1階〜6階の一部 |
| **売場規模** | 延床・対象面積 約19,000㎡ |
| **店舗数** | 約100店舗（エリア初出店を含む計画） |

- <b>既存施設との関係：</b> 大津通をはさんで隣接する名古屋PARCO（西・東・南館）と相乗効果を狙う配置。
- <b>ターゲット層：</b> 百貨店利用の大人世代と、高感度なライフスタイルショップを求める層を橋渡しする構成。
- <b>未発表の項目：</b> 出店する約100店舗の個別ブランド名、具体的なオープン日、開業記念イベントは2026年11月時点で未発表。
