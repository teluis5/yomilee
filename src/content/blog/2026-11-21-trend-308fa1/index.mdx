**経済産業省と次世代自動車振興センター（NeV）のCEV補助金は、2026年11月20日（金）到着分で申請受付を終了**しました。

令和7年度補正予算として確保されていた約1,100億円の予算が、想定を上回る駆け込み需要によって枯渇したためです。

**11月20日17時15分（オンライン申請）以降に届いた案件はすべて不受理**となり、救済措置は発表されていません。

2026年11月21日時点のNeV公式発表をもとに、終了の経緯とこれからEV購入を検討する人の対策を整理しました。

## CEV補助金は2026年11月20日で急遽締切・期限後到着は不受理

**当初は12月頃までの継続が見込まれていましたが、残高約9億3,000万円となった時点で前倒し終了**が決定しました。

連休明けの11月24日以降の申請で予算超過が確実となったための緊急措置であり、郵送・オンライン共に同日が最終期限です。

| 項目 | 受付終了の公式条件 |
| :--- | :--- |
| **対象制度** | 令和7年度補正予算 CEV補助金（EV / PHEV / FCV） |
| **オンライン申請期限** | 2026年11月20日（金）17時15分まで |
| **郵送申請期限** | 2026年11月20日（金）事務局到着分まで |
| **予算残高（直前）** | 約9億3,000万円（当初枠 約1,100億円） |
| **期限後の扱い** | 車両登録済みでも書類未着なら全件不受理 |

- <b>駆け込み急増の背景：</b> 好調なEV販売に加え、2027年以降の補助額減額を見据えた前倒し申請が集中。
- <b>年末登録の救済なし：</b> 11月21日から年末にかけて新車登録される車両向けの追加財源は、現時点で未発表。

## 2027年以降の減額方針と今から使える3つの代替策

**経済産業省は2027年1月1日以降に登録される車両について、補助額の見直し（減額）方針を公表**しています。

国のCEV補助金受付が閉じた今、購入予定者・納車待ちの人は自治体制度や販売店施策の併用確認が欠かせません。

1. <b>都道府県・市区町村の独自補助金：</b> 東京都のZEV補助金など、国とは別枠で通年募集している自治体補助金の残枠を確認。
2. <b>ディーラーとの登録時期相談：</b> 年末登録で補助金ゼロになるか、次期2027年制度の対象になるか販売店と納車日を調整。
3. <b>充電設備・V2H補助の確認：</b> 車両本体以外の充電インフラ補助金やエコカー減税・環境性能割の適用条件を再計算。

> <b>契約前の注意：</b> 車両の「新車新規登録日」と「補助金公募期間」がずれると対象外になります。契約書前に必ずディーラーへ確認してください。

## よくある質問（FAQ）

### Q. 11月20日より前に車を登録済みなら、来週申請しても間に合いますか？
いいえ、事務局への「申請到着日」が11月20日（オンラインは17時15分）を過ぎた分はすべて不受理となります。登録日だけでは救済対象になりません。

### Q. 次の国のEV補助金はいつ再開しますか？
2027年1月1日以降の新車登録車を対象とする見直し案（減額方針）が示されています。具体的な申請開始日は今後の経産省・NeV公表待ちです。
