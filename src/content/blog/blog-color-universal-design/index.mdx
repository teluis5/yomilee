## カラーユニバーサルデザイン（CUD）とは？

カラーユニバーサルデザイン（Color Universal Design：略称CUD）とは、<b>「遺伝的な色覚の違いや加齢に関わらず、できるだけ多くの人に正しく情報が伝わるよう配慮されたデザイン」</b>のことです。

「特別な人のための福祉」ではなく、<b>「すべての読者にとっての情報伝達効率（生活改善・業務改善）を高めるための合理的な設計思想」</b>です。

### 「色覚異常」から「色覚多様性」への呼称の移り変わり
以前は「色弱」や「色覚異常」と呼ばれていましたが、病気や障害ではなく「人間が持つ多様な視覚特性のひとつ」という観点から、日本遺伝学会は2017年に<b>「色覚多様性」</b>という呼称を提案しました。現在では、個人の特性を尊重したポジティブな概念として広く浸透しています。

### 男性の20人に1人！実はAB型の血液型と同じくらい身近
先天的な色覚多様性を持つ人の割合は、<b>日本人男性で約5%（20人に1人）、女性で約0.2%（約500人に1人）</b>と言われています。

日本全体では約300万人以上が存在しており、これは<b>「血液型がAB型の人」とほぼ同じ割合</b>です。クラスや社内の同じ部署に1人は必ずいる計算になり、決して珍しい存在ではありません。

## どのような色の見分けが難しいのか？

色覚多様性を持つ方は、特定の波長の光を感じる細胞（錐体）のバランスが異なるため、特定の組み合わせを見分ける際に混同が起きやすくなります。

![色覚障がいのある方の見え方の例](./rei1.png)

</figure>

一般的には「赤と緑」の区別が難しいことが知られていますが、実際には以下の組み合わせでも判別が難しくなります。

| 見分けにくい色の組み合わせ | 日常・ビジネスで起きやすい問題 |
| :--- | :--- |
| <b>赤 と 緑</b> | 緑の黒板に赤チョークで書かれた文字が見えない、充電完了ランプの赤/緑が分からない |
| <b>濃い赤 と 黒・焦げ茶</b> | <b>「重要な赤文字」が「通常の黒文字」に見えてしまい、強調を見落とす</b> |
| <b>オレンジ と 黄緑</b> | カレンダーの予定の色分けや路線の乗り換え案内で混同する |
| <b>青 と 紫</b> | 折れ線グラフや棒グラフで項目が識別できない |
| <b>ピンク と 水色・灰色</b> | 地図や座席予約画面で空席（ピンク）と指定席（水色）が判別しづらい |

## 身近な成功例：東京メトロの「記号×配色」のハイブリッド設計

カラーユニバーサルデザインの最高峰の実践例として有名なのが、<b>東京メトロ（地下鉄）の路線図とサインシステム</b>です。

東京メトロでは、丸ノ内線（赤）、銀座線（オレンジ）、千代田線（緑）のように路線ごとに鮮やかなラインカラーを設定していますが、<b>「色覚だけに頼らない多重化」</b>が徹底されています。

- **アルファベット（路線記号）の併記**: 丸ノ内線＝<b>M</b>、銀座線＝<b>G</b>、千代田線＝<b>C</b>
- **駅ナンバリング（数字）の導入**: M01、M02など、誰でも順番と位置が分かる仕組み
- **ラインカラー自体の明度・彩度調整**: 似通って見えやすかった路線の色調を再設計し、識別性を向上

色だけに頼らず「形・文字・記号」を組み合わせることで、色覚多様性を持つ方はもちろん、小さな子どもや外国人観光客にとっても直感的に理解できるグローバルな動線設計が実現されています。

## ブログやスライド資料で今すぐ使える5つの実践Tips

日頃のブログ執筆やPowerPoint資料の作成において、誰でも今日から取り入れられる工夫をご紹介します。

### 1. 強調には「暗い赤」ではなく「朱色やオレンジ」を使う
濃いワインレッドや暗い赤は、黒と同化して見落とされやすい代表格です。
強調色を使うなら、少し黄みを含んだ<b>「明るいオレンジ」や「朱色（バーミリオン）」</b>を選ぶと、誰にとっても鮮烈に目立つアクセントになります。

### 2. 色だけでなく「太字（ボールド）・下線・記号」を必ず併用する
文字を目立たせたいときは、色を変えるだけでなく、<b>「太字にする」「記号（⚠️、📌、💡）を添える」</b>という多重の合図を送りましょう。白黒で印刷された場合でも、どこが重要かが一瞬で伝わります。

### 3. グラフは「線の形状（点線・破線）」や「マーカー（●・▲・■）」で差をつける
複数のデータを折れ線グラフで比較する際、色だけで差別化するのは禁物です。実線・点線・破線を描き分けたり、プロット記号の形状を変えたりすることで、色の識別が苦手な方でも完璧に追従できます。

### 4. 隣り合う色の境界に「白や黒のフチ線」を1本引く
円グラフや積み上げ棒グラフなど、似たトーンの色が隣接する場合は、<b>境目に細い白（または黒）のセパレーションライン</b>を挟みましょう。境界線が引かれるだけで、色の違いが格段に識別しやすくなります。

### 5. 「カラーユニバーサルデザイン推奨配色セット」を活用する
配色に迷ったら、東京大学の伊藤啓准教授らが研究・公開している公的な<b>「CUD推奨配色セット」</b>を参照するのが最も確実です。どのような色覚特性でも高コントラストで判別しやすいカラーパレットが体系化されています。

## まとめ

カラーユニバーサルデザインは、「特定の誰かへの親切」にとどまりません。

<ConclusionBox>
- <b>男性の20人に1人が該当</b>: 色覚多様性は極めて身近な個性であり、考慮が不可欠
- <b>色だけに頼らない情報設計</b>: 太字、下線、記号、文字を併用して確実に伝える
- <b>赤よりオレンジ・朱色</b>: 黒と同化しやすい暗い赤を避け、視認性の高いトーンを選択
- <b>すべての人の視認性向上へ</b>: スマホの低輝度モードや直射日光下の閲覧でも抜群に読みやすくなる
</ConclusionBox>

「色に頼りすぎないデザイン」を意識することは、屋外の強い日差しの中でスマホを見ている読者や、白黒印刷で書類を読むクライアントにとっても最大の親切になります。
