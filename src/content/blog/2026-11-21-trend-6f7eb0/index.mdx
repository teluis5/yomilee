**2026年11月21日〜22日に、証明支援系Leanの開発団体Lean FROとMathlibコミュニティが共同声明を発表**しました。

Anthropic数学者レヴェント・アルポゲ氏がClaudeとの協働で公開したコードの検証結果です。**「命題の定式化と形式証明の双方が正当」と認定**されました。

2026年11月20日の初報から最新の共同声明まで、検証の到達点と残る学術プロセスを整理しました。

## Lean FROとMathlib共同声明が認定した2つの事実

**MITのアンドリュー・サザーランド氏ら外部専門家の監査により、Lean 4カーネルでの論理的破綻ゼロが確認**されました。

人間が25万ページ超を手作業で読む前に、コンピュータによる厳密な機械検証が関門を通過した形です。

| 項目 | 2026年11月22日時点の検証状況 |
| :--- | :--- |
| **発表者・使用AI** | レヴェント・アルポゲ氏（Anthropic）× Claude |
| **対象定理** | リーマン予想および一般化リーマン予想（GRH） |
| **公開形式・規模** | Lean 4形式証明コード（175,187モジュール / 約1,700万行） |
| **共同声明の認定** | Lean FRO・Mathlibが「定式化・証明とも正当」と認定 |
| **公式懸賞の扱い** | 査読論文の公開と2年間の検証待ち（現時点は未確定） |

- <b>定式化の正当性：</b> プログラム冒頭に書かれた命題定義が、本来のリーマン予想と正確に一致すると認定。
- <b>標準公理のみの依存：</b> 不正な仮定や抜け道（`sorry`等）を含まず、標準公理のみでコンパイル完了を確認。

## なぜ「まだ公式解決ではない」のか？数学界と懸賞ルールの基準

**形式証明の機械的合格と、人間コミュニティによる査読論文の受容は別ステップ**として扱われます。

米クレイ数学研究所が設ける100万ドル「ミレニアム懸賞問題」の規程では、以下の2条件が必須です。

1. <b>査読付き専門誌への掲載：</b> コンピュータ向けコードではなく、数学者が査読・理解できる論文形式での受理。
2. <b>掲載後2年間の待機検証：</b> 世界中の数学者が数学的アイデアを精査し、反証が出ないまま2年が経過する工程。

- <b>人間の可読性課題：</b> 通常の論文へ書き起こすと25万ページを超える規模のため、人間向けの要約・解説作業が今後の焦点。
- <b>AI協働の転換点：</b> 約6週間の研究後半ではClaudeが証明構築を加速させ、AI×形式検証の時代を印象づけた出来事。

> <b>情報の読み解き方：</b> Leanコードの正しさは公式コミュニティが認定済みです。ただしクレイ研究所の査読2年ルールはこれから始まります。
