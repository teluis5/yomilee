**「アイタウン富山」は2027年9月1日に富山県富山市双代町で開業予定**の大型商業施設です。

富山県報の大店立地法新設届出によると、大阪屋ショップを核店舗に整備されます。

店舗面積は5,506㎡、駐車場は約305〜350台規模の計画です。

2026年11月時点の行政公告および公式プレスリリースに基づき、予定テナントと交通アクセスを整理しました。

## アイタウン富山は店舗面積5,506㎡・2027年9月1日新設予定

**届出日は2026年10月26日（同年11月11日公告）、新設予定日は2027年9月1日**です。

国道41号の双代町交差点近く、ジョーシン富山本店の向かいという視認性の高い立地へ整備されます。

| 項目 | 届出・計画スペック |
| :--- | :--- |
| **施設名称** | アイタウン富山（核店舗：大阪屋ショップ 双代町店） |
| **新設予定日** | 2027年9月1日予定 |
| **所在地** | 富山県富山市双代町29番1 ほか |
| **店舗面積** | 5,506㎡（約1,666坪） |
| **基本営業時間** | 9:00〜21:30予定（開業直後は8:00開店の可能性あり） |
| **駐車場・駐輪場** | 駐車場 約305〜350台 / 駐輪場 95台 |

- <b>駐車場の利用時間：</b> 7:45〜22:00を予定しており、早朝の買い物にも対応。
- <b>未確定の項目：</b> 飲食テナントの具体的なブランド名と各店の最終営業時間は2026年11月時点で未発表。
- <b>駅からの距離：</b> 富山地方鉄道本線「新庄田中駅」から約370m（徒歩約5分）という電車アクセスの良さも強み。

## 大阪屋ショップに加え無印良品やセリアなど人気6業態が集結

**食料品から衣料・生活雑貨・100円ショップ・ドラッグストア・眼鏡まで1カ所で完結**する構成です。

日用品の買い回りに特化したラインナップが揃うため、富山市東部・中心部から高い集客力が見込まれます。

- <b>大阪屋ショップ（食品スーパー）：</b> 地元富山で高い支持を集める生鮮・惣菜充実型の核店舗。
- <b>無印良品（生活雑貨・衣料）：</b> レトルト食品や収納用品、衣料品まで日常使いの需要を取り込む存在。
- <b>スギ薬局（ドラッグ・調剤）：</b> 日用品や医薬品のまとめ買いを食料品と同時に済ませられる配置。
- <b>セリア・西松屋・JINS：</b> 100円ショップ、ベビー・子ども用品、メガネ店に加え飲食店も併設計画。

> <b>注意点：</b> テナント構成や区画数は2026年11月時点の計画段階であり、開業までに一部変更や追加発表が入る場合があります。
