**京都駅東南部エリアの市有地活用として、新施設「（仮称）Link Knot KYOTO」が2030年度に開業する予定です。**

京都市が実施した公募型プロポーザルで、寺田倉庫とデベロップの共同事業体が契約候補事業者に選定されました。

2026年11月時点の京都市公式発表に基づき、全4棟の施設計画、着工・開業スケジュール、現地住所を整理しました。

## 京都駅東南部「Link Knot KYOTO」は全4棟・約6,000㎡の文化拠点

**若手アーティストが「制作・暮らし・仕事・発表」を一体で続けられるアーティストヴィレッジ構想です。**

敷地4,352.14㎡の市有地に延床面積約6,000㎡の4棟を整備し、店舗や宿泊施設も併設する計画になります。

| 項目 | 京都市公表・提案スペック |
| :--- | :--- |
| **事業名称（仮称）** | Link Knot KYOTO |
| **契約候補事業者** | 代表：寺田倉庫株式会社 / 共同：株式会社デベロップ |
| **所在地** | 京都府京都市南区東九条北河原町1番、2番（北河原市営住宅跡地） |
| **敷地面積・延床面積** | 敷地面積 4,352.14㎡（実測） / 全体延床面積 約6,000㎡ |
| **着工予定** | 令和10年度（2028年度）以降 |
| **開業予定** | 令和12年度（2030年度）予定 |

- <b>アート＆クラフトラボ棟：</b> シェアアトリエに加え、一般客も立ち寄れる店舗や事務所スペースを設ける計画。
- <b>アート体験型宿泊施設棟：</b> 滞在しながらアートに触れられる宿泊棟として、観光客や関係者の受け皿になる構成。
- <b>居住2棟の構成：</b> シェアハウス棟とアート付きレジデンス棟を整備し、若手表現者の京都定住を支援。

> <b>未発表の項目：</b> 具体的なテナント店舗名、宿泊料金、開業月の詳細は2026年11月時点で未発表です。

## 寺田倉庫×デベロップ参画で変わる京都駅東南部の3つの注目点

**倉庫・アート保管の知見を持つ寺田倉庫と、コンテナホテル開発などに強みを持つデベロップの連携が核です。**

駅南側の住宅・文化ゾーンに新たなにぎわいと宿泊・商業機能が加わります。

1. <b>店舗とアトリエの併設：</b> 作品展示や販売スペースが整備されるため、観光ついでの立ち寄りスポットとして期待。
2. <b>京都駅東南部エリアの回遊性向上：</b> 崇仁・東九条周辺の文化芸術エリアと京都駅を結ぶ新拠点となる見込み。
3. <b>長期的なまちづくり：</b> 2028年度以降の着工を経て2030年度開業を目指す、中長期の都市再生プロジェクト。
