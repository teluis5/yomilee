## GPT-6.2 SolとChatGPT新機能は無料？有料プランの価格と特徴

<b>「GPT-6.2 Sol」のチャット展開および「Saved reference images」は、ChatGPT Plus（月額20ドル〜）などの有料プラン向けに提供されています。</b>

最上位「GPT-6.2 Astra」より高速かつ低コストな設計。表やグラフの読取精度と長文指示への追従性が大きく向上しています。

API利用料金も入力100万トークンあたり2ドル・出力10ドルと前世代から据え置き。商用アプリ組み込みでもコスト爆発を抑えられる水準です。

さらに「Saved reference images」では人物やペットを「@名前」で登録可能。別チャットでも顔立ちや画風を崩さず画像生成ができます。

毎回プロンプトへ特徴を書き直す手間がなくなるため、SNSアイコンやブログ挿絵のシリーズ統一には非常に実用的な進化です。

## Claude ShipとGoogle AIモード一時的スレッドは何が便利？

<b>Anthropic「Claude Ship」はエンジニアのコードレビュー負荷を激減させ、Google「一時的スレッド」は検索履歴を汚さずAI調査ができます。</b>

各社の11月下旬アップデートにおける目玉機能と対応プランの比較表は下記の通りです。

| 提供元 | 最新機能・モデル名 | 主な用途とメリット |
| :--- | :--- | :--- |
| **OpenAI** | **GPT-6.2 Sol / 参照画像保存** | 表・画像読取と長文追従を強化。@名前で一貫画像生成（Plus等有料プラン） |
| **Anthropic** | **Claude Ship / Skills over MCP** | PR自動修正・承認マージとバックグラウンド処理（MCP Tasks等）を実行 |
| **Google** | **AIモード「一時的スレッド」** | 検索履歴やパーソナライズを残さずAI検索を完結できるシークレット機能 |

Anthropicは同時に「Claude Whiteboards」「Claude Sheets」や「MCP Tasks」も展開。非同期処理とチーム協働に軸足を置いています。

一方でGoogle検索の「一時的スレッド」は、仕事用のリサーチや家族共有端末で検索履歴に混ぜたくない質問を投げる場面で即戦力。

## GPT-6.2 Sol・Claude Shipのよくある質問（FAQ）

### Q. GPT-6.2 Solは無料版ChatGPTでも使えますか？

2026年11月下旬時点では、Plus・Pro・Business・Enterprise等の有料プランが対象。順次ロールアウトが行われています。

### Q. ChatGPTの「Saved reference images」はどう使いますか？

人物やペットの画像をカテゴリ別に保存して名前を付けておきます。別チャットでも「@名前」と指定するだけで同じ特徴の画像を作れます。
