<b>テイクアウトカフェ「Lanaiとどろき」が2026年11月21日（土）にオープン</b>しました。

神奈川県川崎市中原区の等々力緑地内「釣池」北側の住宅街に誕生した、戸建て改装型のアットホームな店舗です。

公園散策の休憩やスタジアム観戦前の立ち寄りスポットとして、営業時間と注目メニューを整理しました。

## Lanaiとどろきは11月21日開業・土日10時〜16時の公園前カフェ

<b>基本営業日は土日・祝日を中心とした10:00〜16:00で、試合開催日には臨時営業も実施</b>します。

「周辺に気軽に寄れるカフェがあれば」という近隣住民や公園利用者の声を受けて誕生したテイクアウト専門店です。

| 項目 | 店舗詳細（2026年11月時点） |
| :--- | :--- |
| **店舗名** | Lanaiとどろき |
| **オープン日** | 2026年11月21日（土） |
| **営業時間** | 土日祝中心 10:00〜16:00（※試合・イベント日は変更あり） |
| **業態** | テイクアウトカフェ（戸建て住宅の一部を改装） |
| **所在地エリア** | 神奈川県川崎市中原区等々力（等々力緑地・釣池北側） |

- <b>応援ムードの店内：</b> ハワイアンテイストの内装に、川崎フロンターレのユニフォームやグッズを飾った空間。
- <b>イベント連動営業：</b> Uvanceとどろきスタジアム by Fujitsuでの試合日にはスケジュールに合わせて開く場合あり。

## 看板メニュー「とどろきブルーアイス」と限定サンドイッチ

<b>手作りサンドイッチや焼き菓子に加え、フロンターレ試合日限定の「とどろきブルーアイス」を提供</b>します。

等々力緑地のベンチやスタジアム観戦のお供に持ち運びやすい軽食とドリンクが揃います。

- <b>とどろきブルーアイス：</b> 川崎フロンターレのチームカラーをイメージした試合日限定スイーツ。
- <b>日替わりサンドイッチ：</b> ランチ需要が高く、イベント日などは売り切れ次第終了となる人気メニュー。
- <b>焼き菓子ラインナップ：</b> 「おかし工房しいの実」のシフォンケーキなど、地域のこだわり菓子を販売。
- <b>ドリンク・雑貨：</b> ハワイアンテイストのドリンクホルダーや各種テイクアウトドリンクを展開。

> <b>完売対策のヒント：</b> サンドイッチは数量限定のため、週末のランチタイムや試合キックオフ直前は早めの来店が安心です。

## 出店場所・Googleマップと等々力緑地からのアクセス

<b>等々力緑地の北西側にある「釣池」の北側住宅街（幹線道路から入った区画）に位置</b>します。

詳細な番地が非公開の住宅改装店舗のため、目印となる等々力緑地（神奈川県川崎市中原区等々力1-1）周辺マップを掲載しました。

## よくある質問（FAQ）

### Q. Lanaiとどろきは平日に営業していますか？
基本は土日・祝日中心の10:00〜16:00営業です。川崎フロンターレの平日ナイトゲーム開催日などは臨時営業や時間変更が行われる場合があります。

### Q. 店内で座って飲食（イートイン）できますか？
基本スタイルはテイクアウト専門のカフェです。購入したドリンクやサンドイッチは、隣接する等々力緑地内のベンチや芝生エリアで楽しむのがおすすめです。
