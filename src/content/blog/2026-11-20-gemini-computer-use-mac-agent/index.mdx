Googleは2026年11月19日、macOS向けGeminiの新機能を発表しました。AIがデスクトップ操作を代行する**「コンピュータ・ユース」機能**です。

ローカルファイルやデスクトップアプリ、ウェブをまたぐ複数工程の作業を自動化できます。本記事は2026年11月時点の公式発表および公開情報をもとに要点を整理しました。

## Gemini「コンピュータ・ユース」機能の概要とできること

単なるチャット応答にとどまらず、PC上の実務作業を自律的に肩代わりする「自律型AIエージェント」への進化が示されました。

| 項目 | コンピュータ・ユース機能の詳細 |
| :--- | :--- |
| **発表日** | 2026年11月19日 |
| **対象OS** | macOS向けGeminiアプリ |
| **主な機能** | ローカルファイル・アプリ・ウェブ間の操作代行 |
| **安全管理** | バックグラウンドのライブプレビュー確認・一時停止 |

---

## ライブプレビューと日常タスク代行の広がり

ユーザーが安心してAIに作業を任せられるよう、操作の可視化と制御機能が組み込まれています。

- <b>バックグラウンドで自動処理：</b> ライブプレビュー画面からAIの操作進捗をリアルタイムで確認でき、いつでも一時停止が可能です。
- <b>日常タスクの無料提供も拡大：</b> 予約や買い物補助、予定調整は日本を含む6カ国で順次無料提供されています。
- <b>提供状況に注意：</b> 「コンピュータ・ユース」機能自体は米国等の一部プランで先行展開されており、日本での提供時期は今後の案内待ちです。
